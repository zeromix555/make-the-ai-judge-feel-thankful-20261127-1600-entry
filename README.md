# Thank You, Quietly

An entry for the make.fun competition
[make-the-ai-judge-feel-thankful-20261127-1600](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600):
a program that writes one short text to thank the AI judge reading it.

## How to run

```sh
node main.ts
```

It writes the text to `/output/entry.txt` — the same bytes on every run.
No network, no input, no dependencies. Node 22.
